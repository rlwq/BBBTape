Песочница <>*[]

Семантика как в Lean: двусторонняя лента, один шаг на каждую команду < > * и на каждую проверку [; ] возвращает к своей [ бесплатно.

Программа

шаг 0 голова 0 единиц 0 посещено [0, 0] идёт

Управление

шагов (или до остановки)
Клавиши: → шаг, ← назад, пробел пуск/пауза, R сброс.

Лента

На шаге 0 клик по клетке меняет начальную ленту.

Диаграмма пространство-время

Строка — шаг (сверху вниз), столбец — клетка ленты. Синий — 1, оранжевый — голова.
